# BE ASPX Admin — Clean Architecture 4 tầng (không đụng FE)

## Context
FE `ai-website-cloner-template` (Next.js, clone ROG ASUS VN) hiện hardcode toàn bộ nội dung: 6 hero slides, 22 danh mục sản phẩm, 5 bài Highlights + 9 bài Listing, PromoBar, JoinRepublic, Footer (5 link + 2 legal + 5 social + thông tin công ty). Chưa có backend nào.

Yêu cầu đã chốt: **ASP.NET Core Web API + SQL Server LocalDB**, **Clean Architecture 4 tầng**, phạm vi: đăng nhập/phân quyền + CRUD nội dung chính + cấu hình site + REST API công khai trả đúng shape dữ liệu FE. **Tuyệt đối không sửa/thêm file nào vào thư mục FE** — BE nằm song song tại `apsx/RogAdmin/`.

## Kiến trúc 4 tầng
```
RogAdmin.Api (Tầng 4 - Presentation)   → Controllers, Program.cs, middleware, wwwroot/admin UI
    ↓ references
RogAdmin.Application (Tầng 2 - Logic)  → DTOs, Service interfaces + Services, Validators
    ↓ references
RogAdmin.Domain (Tầng 1 - Core)        → Entities, Enums — không phụ thuộc gì
RogAdmin.Infrastructure (Tầng 3)       → DbContext, Repositories, JWT, PasswordHasher, Seeder
                                          (references Application, implement interface của Application;
                                           DI wiring tại Api = composition root)
```

Kèm **admin UI tĩnh** (`Api/wwwroot/admin/`: login + trang bảng CRUD, vanilla JS + fetch, tiếng Việt, không build step) để quản trị được ngay mà không cần FE.

## Schema chính (map đúng field FE)
- **Article**: Title, Excerpt, Tag (giữ prefix `// ` như FE), ImageUrl, Href, PublishedDate, Section, IsBig (2 bài lớn/3 nhỏ của Highlights), SortOrder, IsActive
- **HeroSlide**: ImageUrl, AltText, Href (FE đang `#` — cho nullable), SortOrder, IsActive
- **ProductCategory**: Label, ImageUrl, Href, SortOrder, IsActive
- **FooterLink**: Label, Href, Group, SortOrder, IsActive
- **SiteSetting**: Key/Value (promoBarText/Url, joinRepublic*, company*, newsletter*, badgeUrl...)
- **AdminUser**: Username, PasswordHash+Salt, FullName, Role, IsActive

## Seed data
Seeder idempotent, copy nguyên giá trị từ FE component (đọc trực tiếp `RogHeroCarousel/RogProductCategories/RogHighlights/RogArticleListing/RogFooter/RogJoinRepublic/RogPromoBar.tsx` khi implement — chỉ đọc, không sửa): 6 slides, 22 categories, 14 articles, 12 footer links, toàn bộ site settings. Tài khoản: `admin/Admin@123` (Admin), `editor/Editor@123` (Editor).

## Auth/phân quyền
- JWT Bearer (HS256, expire 8h) cho mọi route `/api/admin/*`; `[Authorize(Roles="Admin,Editor")]`, tạo user để làm sau (v1 không CRUD user).
- Public `/api/public/*` anonymous + CORS cho FE localhost:3000.

## Database & migrations
- Default: **SQL Server LocalDB** (chuẩn Windows/VS cho bạn).
- EF Core 9 code-first, `Database:Provider` = SqlServer|Sqlite chọn lúc startup — SQLite chỉ để **verify trên máy Linux này** (không có SQL Server), connection string LocalDB vẫn là mặc định ship đi.
- Migration `Init` generate bằng dotnet-ef, startup tự `Database.Migrate()` + seed.
